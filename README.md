> **Archive notice.** This repository preserves an archived master's-level student project from the University of Bonn. ## Overview

The thesis studies the two-sample problem of testing whether independent samples of functional observations are generated by the same distribution. It develops the Hilbert-space and functional-data background needed for the permutation framework of Bugni and Horowitz (2021), including its Cramér-von Mises-type and mean-focused components, and implements the procedures in R.

The simulation study examines the behavior of the original testing procedure across controlled functional-data designs. The empirical application uses half-hourly Adelaide electricity-demand curves and compares cleaned, detrended, and deseasoned workday and Saturday observations.

The thesis also explores a persistence-focused variant of the Cramér-von Mises-type procedure. The variant standardizes the functional observations to focus the comparison on differences in their dependence or persistence structure; it is presented as an extension investigated within the thesis, without claiming conclusions beyond the documented simulations and discussion.

## Repository guide

- [`LaTeX/`](LaTeX/) contains the submitted PDF, thesis source, bibliography, and compilation artifacts.
- [`Code/PermFDATest/`](Code/PermFDATest/) contains the package-style implementation and its tests and function documentation.
- [`Code/MA_Cluster_Scripts/`](Code/MA_Cluster_Scripts/) contains the simulation inputs, R scripts, Slurm launch scripts, and some saved cluster outputs.
- [`Code/MA_Scripts/Simulation_Analysis/`](Code/MA_Scripts/Simulation_Analysis/) contains the simulation post-processing scripts.
- [`Code/MA_Scripts/Application/`](Code/MA_Scripts/Application/) contains the Adelaide data preparation and testing workflow.
- [`Code/MA_Scripts/Plot_Generators/`](Code/MA_Scripts/Plot_Generators/) contains scripts used to produce thesis figures.
- [`Data/`](Data/) contains processed electricity-demand objects, application results, and saved simulation outputs. [`Graphics/`](Graphics/) contains generated figures used in the thesis.

Students should begin with the thesis PDF and use its simulation and application sections to identify the corresponding scripts. There is no separate replication manual or single end-to-end runner in the repository.

## Reproducibility note

- The analysis was conducted in **R**. The method implementation is in [`Code/PermFDATest/`](Code/PermFDATest/), while the simulation and application workflows have separate entry points described above.
- Processed application data and saved simulation results are included under [`Data/`](Data/). The first application script obtains the original Adelaide day-of-week demand series from the external `fds` R package rather than downloading a separate data file.
- Rebuilding the project requires the R dependencies named in the package [`DESCRIPTION`](Code/PermFDATest/DESCRIPTION) and in the individual scripts. Package versions are not pinned in a lockfile, and the cluster simulations assume a Slurm environment.
- Seeds are recorded for the main simulation-input workflow, but some persistence and application scripts sample seeds at runtime. The repository has not been comprehensively modernized or revalidated under current R and package versions, so complete end-to-end reproduction remains unverified.
